# Simple QR Code Generator

A clean, responsive web application that generates downloadable QR codes from any text or URL input in real-time. 

## ✨ Features
* **Instant Generation:** Converts text or links into a QR code instantly.
* **Clean UI:** Built with a modern, accessible color palette.
* **Clear Functionality:** Easily reset the workspace with a dedicated clear button.
* **Responsive Design:** Adapts smoothly to different screen sizes.

## 🛠️ Tech Stack
* **HTML5** for structure
* **CSS3** for styling and layout (Flexbox)
* **Vanilla JavaScript** for logic
* **[QRCode.js](https://davidshimjs.github.io/qrcodejs/)** for rendering the QR codes
